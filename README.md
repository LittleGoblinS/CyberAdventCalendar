# Operation North Pole – v2.1

Interactive Level 3 cyber security advent calendar with 24 questions and 24 extension challenges. Includes team and classroom modes, optional synthesized festive music and effects, volume control and browser read-aloud. No student accounts or database required. Scores are local to the current tab.

## Hosting
Enable GitHub Pages in Settings > Pages, select Deploy from a branch, main, /(root), and Save.
